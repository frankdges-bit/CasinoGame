# CasinoGame

CasinoGame is a text-based Java game set in a mysterious casino. The player must fight different enemies, earn coins, purchase upgrades, and survive multiple stages to defeat the final boss.

## Features

* Dice-based combat
* Multiple enemies and stages
* Player health, luck, and coins
* Item store and upgrades
* Final boss battle

## How to Run

1. Download or clone the repository.
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Run `Main.java`.
4. Follow the instructions displayed in the console.
